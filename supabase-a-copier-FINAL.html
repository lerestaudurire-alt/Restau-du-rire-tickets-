Supabase : à copier

Appuyez sur « Copier », puis collez dans Supabase (aucune sélection manuelle nécessaire).

1SQL (SQL Editor)

Supabase → SQL Editor → tout effacer → coller → Run. Relançable sans risque.

2Code de la fonction de paiement

Edge Functions → votre fonction (dynamic-action) → Code → tout effacer → coller → Deploy.
